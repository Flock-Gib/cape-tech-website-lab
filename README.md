# Build a Website in 5 Minutes

A walk-up activity for Cape Cod Tech’s IT Shop Tech Night. Pick a fictional
business, take on a playful mission, edit its words and style, and find each
change in the live HTML/CSS. Build an alien arcade, a superhero pet rescue, or a
taco truck on Mars. Choose an emoji mascot, a system font, and a background pattern.
Take turns: one person chooses an edit, the other finds the code, then swap.

## Run locally

Open `index.html` in a modern browser. No installation, build, server, or internet
connection is required. Keep `index.html`, `styles.css`, and `script.js` together.
All edits stay in the current page; nothing is sent or saved. Reloading or
choosing **Start Over** restores the default activity. Picking another starter
replaces your edits and resets the challenge.
Complete all three mission steps to earn a Website Creator badge and a short
confetti celebration. Progress reflects the current edits; restoring a default
undoes that step. Confetti plays only once per mission attempt and is disabled
when the visitor prefers reduced motion. All fonts, patterns, and effects work
offline without external services or dependencies.

## Quick check

- Load each of the three starters; check its heading, paragraph, and two colors.
- Type in both text fields; check the preview, escaped HTML, and marked code line.
  Try `<strong>Hello</strong>`: it must appear as text, not formatted HTML.
- Change each color; check the preview, hex label, and marked CSS property.
- Change the heading, background color, and any mascot/font/pattern; check all
  three mission steps, the progress bar, badge, and HTML/CSS explanation.
- Try every font, pattern, and mascot, including no mascot. Check the preview and
  matching code highlight; the default style choices do not complete the style step.
- Complete a mission; check that confetti clears and does not repeat on further
  edits. Undo a step; check that progress and badge reflect it. Enable reduced
  motion; complete a fresh mission and check that the badge appears without animation.
- Switch starters; check the new mission, reset style controls, and cleared progress.
- Choose **Start Over**; check the original arcade, fields, colors, challenge,
  cleared code highlight, and keyboard focus on the first starter.
- Use Tab and the radio group’s arrow keys to navigate. Check visible focus and
  a narrow phone-sized window for stacked sections and no horizontal page scroll.

## Publish with Render

Create a **Static Site** connected to this repository. Select `main`, leave
**Root Directory** and **Build Command** blank, and use `.` for **Publish
Directory**. Deploy the latest commit and wait for the deployment to say **Live**.
No server or package installation is needed.

## Publish with GitHub Pages

1. Commit these files to the repository’s default branch.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the default branch and **/ (root)**, then **Save**.
4. Open the published URL shown in Pages after deployment completes.

The relative stylesheet and script links work on repository Pages URLs as well
as local files. The code panel shows the preview’s HTML body and matching CSS,
not the surrounding activity interface.
